# Decisions

Short records of durable choices that are **currently in force** and that a maintainer or agent would otherwise have to reconstruct. A record states the decision and its consequences and summarizes its evidence. The detailed validation records are kept by the maintainer and are not part of this distribution.

**A record never overrides the runtime files.** The workflow is defined only by `SKILL.md`, `agents/`, `modes/`, `templates/`, `writers/`, `scripts/` and `profiles/`. If a record and a runtime file disagree, the runtime file governs, and the record is wrong and must be fixed. When a decision is replaced, mark its status `Superseded by <record>` and add the new record. Do not edit history in place.
