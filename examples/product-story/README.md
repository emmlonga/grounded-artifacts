# Example: a written product story

**This is a synthetic test fixture, not a real person's story.** The planning document, the owner's answers and the company are invented to test the workflow. For publication, the fictional setting was generalized: no country, and placeholder names for the bank and its payments partner. The workflow outputs shown are those the run produced, with only those renamings carried through.

**The situation.** A product manager writes a two-page, first-person story of an automatic-savings feature for product-manager interviewers, who judge product sense, product execution and narrative clarity. The only source is a planning document drafted with an AI planning session and never reviewed by the owner. It mixes the owner's statements with the planning agent's inferences and estimates, and it does not say who found the problem or who set the vision.

**What it shows.** How the workflow refuses to turn plausible material into claims: a readiness check that blocks and asks, a grounding that writes down who did what, audits that catch the same ownership overstatement at three layers, and a final story whose "I" means what the source supports.

## Read in this order (about 10 minutes)

| File | What it shows |
|---|---|
| `brief.md` | The artifact's job: audience, criteria, budget, guardrails |
| `source-input.md` | The planning document as the workflow received it, traps included |
| `what-the-workflow-changed.md` | The readiness questions and owner answers, the ownership line, the audit findings at each layer |
| `grounding-excerpt.md` | The grounding the draft was written from: claim classes, constants, anonymization map, terminology, open items |
| `final-artifact.md` | The final story (`final-artifact.pdf` is the same text rendered with the `plain` profile) |

## Limits

The run predates the story-frame layer, so it does not show the frame gate. The owner's answers were written for the test, and the auditors are AI agents. Audit files, adjudication history and intermediate versions are not included.
